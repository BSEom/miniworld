## 프로젝트 개요
- **프로젝트명**: 기분 정거장
- **목표**: 사용자가 미니홈피(미니룸)를 생성하고 감정(mood)에 따라 테마가 바뀌며, 다이어리/사진첩/친구 기능을 사용하는 개인 소셜 공간 구현
- **핵심 기능**: 회원가입/로그인, 미니룸 자동 생성 및 아이템 배치, 감정별 테마(헤더/배경/버튼/다이어리), 다이어리 CRUD, 사진첩, 유저 검색, 계정 복구 기능

- 프론트에서 로그인/회원가입이 백엔드 엔드포인트에 요청을 보내고 응답을 받는가

**목표**

**세부 작업**

- 로그인 API: 인증 로직, JWT 발급(혹은 세션 설정)
- 다이어리 테마: 다이어리 뷰에서 `mood`에 따라 CSS/템플릿 변경
- 미니룸 생성: 회원가입 또는 최초 로그인 시 샘플/기본 미니룸 레코드 생성

- 미니룸 편집 UI(아이템 드래그&드롭 시 좌표 저장 호출)
- 다이어리 작성/열람 시 테마 적용

**백엔드 포인트**
- `POST /api/users/register` (완성)
- `POST /api/users/login` (완성)
- `POST /api/minirooms` (미니룸 생성)
- `POST /api/minirooms/{userId}` (아이템 배치 저장)

**산출물**
- 회원가입/로그인 API 문서 및 테스트 케이스
- 미니룸 생성/아이템 저장 API
- 감정별 다이어리 테마 반영 화면

**완료 기준**
- 회원가입 시 DB에 유저가 정상 저장되고 미니룸 레코드가 생성되는가
- 미니룸 편집 후 서버에 아이템 위치가 저장되는가
- 로그인/회원가입에 대한 서버측 검증(중복, 포맷 등)이 작동하는가
